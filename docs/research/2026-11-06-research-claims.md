`tests/proofs/test_research_claims.py` checks table coverage, explicit verdict/source/limit cells, input hashes and pending #129 slots within the existing pytest proof harness. **Lesson for the canonical handbook/rule:** preserve both the source's dated state and later superseding evidence. A local capture recommendation is not GitHub transport; an index is not shared agent memory; a published leg is not a pair of syntheses.
