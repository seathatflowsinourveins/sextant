## Method
1. **The pinned study, verbatim.** `scripts/research/b_exit_replay.py` at the same commit (SHA-256 `143ab1dd…`), run with no edits. Run alone on the files, it reproduced all 98 rows × 12 columns of the write-up's Appendix A (1,176 cells, 0 mismatches) in 29 s.
2. **From the catalog.** The bars were written to a NautilusTrader v2.0.0rc7 `ParquetDataCatalog`, one `Equity` and one 1-minute `EXTERNAL` bar series per symbol, stamped at bar close. They were then read back and handed to the same `run()` through its `load_bars` seam.
   - The catalog's bars equal the study's own loader output; otherwise the run stops.
   - Nautilus `Bar` has no VWAP field, so `vw` is joined from the same hash-checked file.
   - Compared with step 1, every report value is equal. 617 values differ only in trailing zeros (`-6.0000` against `-6.000000`), because the catalog's `Price` carries 4 decimals.
3. **The table check.** The catalog run's 98 rows match [Appendix A](2026-11-06-exit-study-41/appendix-a.md) cell for cell. That excerpt is copied verbatim from the write-up.
4. **The ledger.** Every arm (96 variants, `hold_flat` and `actual_fifo`) is a [trial row](2026-11-06-exit-study-41/trials.jsonl), tier MODELED, bound to the study's SHA-256 and the three input hashes.

## Result
- **Selection reproduced:** the same frozen pick, `C5-n22-k3-R-OFF`. Two variants pass the exploratory screen; 87 have nonpositive stressed expectancy and 7 fail day stability.
- **Hold beats every variant at both costs.**
- **Actual FIFO exits:** −21.00/−26.99 bps.
- **Limits:** none of the write-up's limits change. This is a minute-bar study with assumed costs, 1,025 correlated entries over three days, and one selection pass with no walk-forward, CPCV, DSR or PBO. It is not merit under ADR-0019.
