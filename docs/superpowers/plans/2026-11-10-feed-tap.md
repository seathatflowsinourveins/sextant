# Read-only feed tap and capacity gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only tap inside `AlpacaTickFeed` measures one-socket receipt lag, handler service and per-symbol flow into a per-second sidecar, and a separate analyzer evaluates the pre-registered capacity gate.

**Architecture:** `FeedTap` is a pure observer called at handler entry/finish, per-second buckets switched by the stream thread, a daemon writer thread (never the handler) appends one JSON line per wall-clock second, and `feed_capacity` is a read-only analyzer with no import of the feed or the broker SDK. Default OFF: `AlpacaTickFeed` without a tap runs the same code path and clocks as today.

**Tech Stack:** Python 3.13 stdlib only (`threading`, `json`, `statistics.NormalDist`, `zoneinfo`), pinned alpaca-py 0.44.0 handler dispatch, pytest proofs with fakes.

**Spec:** the feed-tap brief (sha256 `8e40d158…`), which carries the reconciled design at section 5 of `tasks/entry-ages-screen/REPORT.md` (sha256 `1b9c5f7a…`) and LEAD-0216 (sha256 `aea0914e…`).

## Global Constraints

- NO ORDER PATH: no submit, cancel, resize or subscription change; no second stream, socket, connection or process; no broker key or endpoint.
- Default OFF and byte-identical when off; the proof asserts identical delivered ticks, identical `time.time_ns` call counts, and no file.
- No I/O in the handler; counters are plain integers on per-second buckets written by one thread.
- `DEFAULT` values with authority missing stay unavailable: `entry_input_max_age_s` is a required analyzer argument with no default.
- Never edit `tests/repo/test_budgets.py`; src stays under 28,000 lines (25,985 measured at branch start).
- `c_live_main.py` and `c_session.py` are the track-1 writer's; this branch only reports the call-site change.

## Review Focus

- A handler exception must still record service time and must never be masked by the tap.
- A clock step backward must not resurrect a flushed second or drop a sample silently.
- The writer thread must never raise into the feed; a failed write disables the sidecar only.
- The analyzer must never print a symbol or a price, only counts.
- A sidecar truncated by a kill (no final symbols line) must be usable, with per-symbol coverage marked UNKNOWN.
