# Paper C records implementation plan

> **For agentic workers:** Use superpowers:executing-plans; native execution is required by the dispatch.

**Goal:** Persist C's entry diagnostics and publish the trial before its receipt.
**Architecture:** Record refusals at the existing decision branches without changing decisions. Retain segment snapshots in the receipt. Use TrialLog.append's atomic checkpoint before publishing the receipt, then identify the local trial file by absolute path and SHA-256.
**Tech Stack:** Existing CSession, TrialLog, Python JSON and hashlib.
**Spec:** Lead records ruling of 2026-11-10; ADR-0018.

## Global constraints

- Local commits only; no broker calls, shared ledger, collector or backfill.
- No order, sizing or registry changes; exact Decimal strings in JSON.
- Upstream: northstar-trading@8256c16c31dcb8e53fc726e0c1c77dc2c8d0d4fa, validation/trials.py and persist.py (retained local TrialLog API), ADR-0004 entry predicates.
- TrialLog.finish_arm_run changes state/error only, so pre-registering frozen final counts would require a new API. Publish the completed counts before the receipt instead; scope is the receipt-to-row kill window.

## Review focus

- Refusals that later clear must remain recorded.
- Stale or absent quotes must explain an armed symbol with no entry.
- Segment rollover must retain earlier symbols and reasons.
- A kill immediately after receipt publication must find a durable row.
- A failed ledger append must leave a diagnostic receipt and nonzero exit.
